# C7R BOT

بوت إدارة داخلي لسيرفر C7R — نقاط، مناوبات، تذاكر، تقديم، وسجلات مراقبة كاملة.

## المميزات
- 🕒 **مناوبات**: زر بدء/إنهاء مناوبة، يحتسب الوقت والنقاط تلقائياً.
- 🎫 **تذاكر/مهام**: أزرار استلام وإنهاء، تعطي نقاط عند الإنجاز.
- 🔗 **ربط مع بوتات تذاكر أخرى**: يراقب رسائل بوت التذاكر المحدد ويحاول رصد كلمة الاستلام تلقائياً + أمر `/استلام-تذكرة` كطريقة يدوية مضمونة دائماً.
- 🏆 **نقاط ومتصدرين**: `/نقاطي`, `/المتصدرين`, `/إضافة-نقاط`, `/خصم-نقاط`.
- 📝 **تقارير**: `/تقرير` يفتح استمارة ويرسلها لقناة السجلات.
- 📋 **تقديم**: لوحة بزر "تقديم" تفتح استمارة أسئلة، ترسل لقناة المراجعة مع أزرار قبول/رفض.
- 🛡️ **مراقبة كاملة**: كل حظر/طرد/كتم/تعديل رتبة تقوم به الإدارة يُسجَّل تلقائياً عبر سجل تدقيق ديسكورد الرسمي. كل رسالة محذوفة أو معدّلة تُسجَّل في قناة سجلات منفصلة.

## 1) إنشاء تطبيق البوت
1. روح لـ https://discord.com/developers/applications واضغط **New Application**، سمّه `C7R BOT`.
2. من تبويب **Bot**: اضغط **Reset Token** وانسخه (هذا هو `DISCORD_TOKEN`).
3. من نفس الصفحة فعّل **Privileged Gateway Intents** الثلاثة: `SERVER MEMBERS INTENT`، `MESSAGE CONTENT INTENT`.
4. من تبويب **OAuth2 → General** انسخ **Application ID** (هذا هو `CLIENT_ID`).
5. من **OAuth2 → URL Generator**: اختر `bot` و `applications.commands`، وفي صلاحيات البوت اختر: `Send Messages`, `Embed Links`, `Manage Roles` (إذا بتربطه بأدوار), `View Audit Log`, `Read Message History`. انسخ الرابط الناتج وافتحه لإضافة البوت لسيرفرك.
6. آيدي سيرفرك (`GUILD_ID`): فعّل وضع المطور من إعدادات ديسكورد (Advanced → Developer Mode)، ثم كليك يمين على السيرفر → Copy Server ID.

## 2) تجهيز المشروع محلياً
```bash
npm install
cp .env.example .env
```
افتح `.env` وحط فيه القيم الثلاث اللي جمعتها.

```bash
npm run deploy   # يسجل كل الأوامر على سيرفرك
npm start        # يشغل البوت
```

## 3) الاستضافة (أسهل خيار: Railway)
1. روح لـ https://railway.app وسجل دخول بحساب GitHub.
2. ارفع مجلد المشروع لمستودع GitHub جديد (أو استخدم "Deploy from local folder" لو متوفر).
3. من Railway: **New Project → Deploy from GitHub repo** واختر المستودع.
4. من تبويب **Variables** أضف `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID` بنفس القيم من `.env`.
5. من **Settings → Deploy**: خلي أمر التشغيل `npm start`. Railway بيشغّل البوت 24/7 تلقائياً.
6. لتسجيل الأوامر أول مرة، تقدر تشغّل `npm run deploy` مرة وحدة من تبويب Shell بتاع Railway، أو شغّلها من جهازك قبل الرفع.

## 4) الإعداد داخل ديسكورد (بعد تشغيل البوت)
كل هذي أوامر إدارة، شغّلها مرة وحدة:
```
/config logchannel #سجلات-الإدارة
/config messagelogchannel #سجلات-الرسائل
/config reviewchannel #مراجعة-التقديم
/config staffrole @الإدارة
/config ticketpoints 5
/config dutypoints 2
```
لربط بوت تذاكر خارجي (اختياري):
```
/config addticketbot <آيدي_البوت_الآخر>
```

ثم انشر اللوحات في القنوات المناسبة:
```
/لوحة-المناوبة     → في قناة الإدارة
/لوحة-المهام       → داخل كل تكت أو قناة عمل
/لوحة-التقديم      → في قناة التقديم العامة
```

## 5) ملاحظة مهمة عن ربط بوتات التذاكر الأخرى
البوت يحاول يقرأ رسائل بوت التذاكر المحدد ويرصد كلمة استلام + منشن عضو تلقائياً. لكن كل بوت يكتب رسائله بصيغة مختلفة، فما نضمن يشتغل مع كل البوتات 100%. الطريقة المضمونة دائماً: أي عضو إدارة يشغّل أمر **`/استلام-تذكرة`** داخل قناة التكت بعد ما يستلمه من البوت الثاني، وبكذا تُحتسب نقطته أكيد.

## البيانات
كل شيء يُخزَّن محلياً في `data/db.json` (يُنشأ تلقائياً أول تشغيل). خذ نسخة احتياطية منه بين فترة وفترة إذا الاستضافة ما توفر تخزين دائم.
